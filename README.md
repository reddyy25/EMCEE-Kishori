# EMCEE Kishori — Premium Portfolio

A lightweight, responsive, single-page EMCEE portfolio built with plain HTML, CSS and JavaScript.

## Run in VS Code

1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. All images used by the website are in `assets/images/` and originate from the supplied PDF asset extraction.

## Structure

- `index.html` — semantic page structure and content
- `styles.css` — responsive design, animation and layout
- `script.js` — mobile menu, scroll reveal, counters and gallery lightbox
- `assets/images/` — source images extracted from the supplied EMCEE PDF
- `assets/EMCEE_source.pdf` — source PDF reference
